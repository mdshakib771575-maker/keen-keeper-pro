# 👥 KeenKeeper — Keep Your Friendships Alive

KeenKeeper is a modern friendship tracking application built with Next.js. It helps users stay connected with friends by tracking interactions, managing relationship goals, and visualizing communication analytics.

## 🌐 Live Demo

🔗 Live Site: https://vercel-project-keen-keeper-pro.vercel.app

## 💻 GitHub Repository

🔗https://github.com/mdshakib771575-maker/keen-keeper-pro
---

## 🚀 Features

- 👥 View and manage friend profiles
- 📞 Quick Check-In with Call, Text, and Video
- 📜 Automatic interaction timeline
- 📊 Friendship Analytics using Recharts
- 🔍 Filter timeline by interaction type
- 🎯 Relationship goal tracking
- 🔔 Toast notifications
- ⏳ Loading animation while fetching data
- ❌ Custom 404 page
- 📱 Fully responsive design
